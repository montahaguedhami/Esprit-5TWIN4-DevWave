# Guide manager — Projets et Financements

## Ce que vous pouvez faire

- Consulter la liste de tous les projets et leur état de financement.
- Créer, modifier ou supprimer des projets.
- Consulter toutes les demandes de financement (tous citoyens confondus).
- Accepter ou refuser une demande en attente (un motif est obligatoire pour un refus).
- Consulter le tableau de bord budgétaire (nombre de demandes, montants, etc.).
- Exporter le rapport budgétaire au format CSV ou PDF.
- Consulter les demandes en attente de décision.

## Ce que vous ne pouvez pas faire via le chatbot

Le chatbot est un assistant en lecture seule. Il ne peut pas :

- Créer une demande de financement.
- Accepter ou refuser une demande.
- Modifier un projet ou un budget.
- Déclencher un paiement.
- Modifier un rôle ou une permission.

Toute action de gestion doit être effectuée depuis l'interface manager dédiée.

## Statistiques accessibles

Le manager peut consulter via le chatbot :
- Le nombre total de demandes de financement.
- Le nombre de demandes en attente, acceptées, refusées, payées.
- Les montants globaux de financement par projet.
- Le rapport budgétaire détaillé par projet et par source.
