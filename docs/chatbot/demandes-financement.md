# Demandes de financement — AquaSecure

## Statuts d'une demande

| Statut | Signification |
|--------|---------------|
| `en_attente` | Soumise, en attente de décision du manager. Aucun montant n'est déplacé. |
| `acceptee` | Approuvée par un manager. Le montant est réservé sur le projet. |
| `refusee` | Refusée par un manager, avec un motif obligatoire. Non payable. |
| `payee` | Contribution confirmée. Un Financement a été enregistré. |

## Étapes pour le citoyen

1. Consulter les projets ouverts au financement.
2. Cliquer sur « Contribuer à ce projet » sur la page d'un projet.
3. Saisir un montant d'au moins 1 000 TND.
4. Envoyer la demande : elle passe en statut `en_attente`.
5. Attendre la décision du manager.
6. Si acceptée, confirmer le paiement simulé sur la page de récapitulatif.
7. Consulter le résultat et télécharger le reçu.

## Propriété des données

Un citoyen ne peut consulter que ses propres demandes de financement.
Il ne peut pas consulter, accepter ou refuser les demandes d'autres citoyens.

Seul un manager peut consulter l'ensemble des demandes, les accepter ou les
refuser.
